# Channel Operations

Public documentation for Channel Operations, an owner-operated Google Apps Script utility for uploading videos from Google Drive to YouTube.

## Public pages

- [Overview](https://channel-ops-hub.github.io/channel-operations/)
- [Privacy policy](https://channel-ops-hub.github.io/channel-operations/privacy.html)
- [Terms of use](https://channel-ops-hub.github.io/channel-operations/terms.html)

## Repository contents

- `index.html` — Application overview
- `privacy.html` — Data access, storage, retention, and deletion policy
- `terms.html` — Terms of use

This repository hosts the documentation website. The uploader runs separately in the operator's Google Apps Script project.

## Current status

The current setup version is configured for one channel and supports connection checks, a private test upload, and upload-status checks.

Scheduled publishing, unattended operation, and additional channel configurations are planned and require implementation and verification before use.
