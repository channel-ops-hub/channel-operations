Tweak Relay Uploader

An upload utility for the owner of the Tweak Relay channel, connecting selected Google Drive videos to the owner’s YouTube channel.

Privacy policyTerms of use

What the tool does

The owner runs the utility in Google Apps Script and authorizes access through Google. It checks the configured account and channel, reads a designated video from Google Drive, and transfers that video to YouTube using YouTube API Services. It can then check the upload and processing status.

The tool is for the owner’s channel workflow. It is not offered as a public upload service. This website provides documentation; it does not sign visitors in or request access to their Google accounts.

Channel: Tweak Relay on YouTube.

Current release

The setup release supports account and channel checks, verification of a designated test file, one private test upload, and inspection of its processing status. Duplicate-upload checks help the operator identify an earlier attempt.

Production scheduling and unattended publishing are still being implemented and verified. The current test utility does not publish videos publicly or create recurring triggers.
